# Monetize Connect
A mobile-first influencer marketplace SaaS.

## Tech Stack
- Frontend: Next.js (App Router), Tailwind CSS, Zustand
- Backend: NestJS, PostgreSQL (Neon), Prisma
- Cache: Redis (Upstash)
- Core features: JWT Auth, Real-time chat (ZegoCloud/Socket.io), Escrow payments (Razorpay), Email verification (Resend)
